# 🚀 Projeto Rover

## 📖 Sobre o projeto

Este projeto consiste em um pequeno sistema em **JavaScript** responsável por inicializar os sistemas de um Rover

Ao ser executado, o programa informa no console que os sistemas foram iniciados e apresenta o status dos **painéis solares** e da **bateria**

## ⚙️ Funcionamento

O programa possui uma função chamada `inicializarRover()`, que exibe as seguintes informações:

* Sistemas do Rover iniciados
* Painéis solares: OK
* Nível de bateria: 100%

## 💻 Tecnologias utilizadas

* JavaScript
* Node.js (opcional, para execução pelo terminal)

## ▶️ Como executar

1. Tenha o **Node.js** instalado.
2. Salve o código em um arquivo chamado `rover.js`.
3. Execute pelo terminal:

```bash
node rover.js
```
